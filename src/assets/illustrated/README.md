# Illustrated table artwork

17 transparent PNGs generated with the built-in `image_gen` tool on 2026-11-12.
The exact prompt for every image is in `prompts.json` and embedded in its PNG.
The original generated files remain in the tool's generated-images directory;
the copies in this directory are the project-bound assets.

- `napa`, `enoki`, `tofu`, `beef`, `lotus`, `noodles`, `bok`: food and its ceramic
  plate are painted together, in the same elevated view, light and pigment palette.
- `pot`: warm two-way broth with painted steam; `empty-pot`: a matching empty
  vessel for the actual zero-broth state. This is static illustration, not cooking
  simulation. The broth catalog thumbnail intentionally reuses `pot`.
- `friend-*`: seven fictional, distinct portraits for the original six friends
  and Casey. Additional guests reuse this pool by stable ID; there is no claim
  of a unique portrait generator or uploaded real-person likeness.
- `empty-seat`: the illustrated chair used to invite the vegetarian friend.

The images are new artwork, not photo assets with CSS blur. They contain no UI
labels or quantity claims; counts, names, costs and controls remain semantic HTML.
The original nine assets in the parent directory are retained for the old UI in
Git and are not imported by the illustrated playable-table route. No temporary
geometric food placeholder is used on that route.
